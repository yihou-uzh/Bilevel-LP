This repository contains code and test instances for three problem classes: **BBLIP**, **BLIPI**, and **MKIP**. Below is a quick overview of the files in each folder.

---

## BBLIP Instance

The **BBLIP** folder contains the generated **BBLIP** test instances and the code for generating them.

- **`BBLIP_instances.py`**: generates random test instances and writes them to `BBLIP_instances.json`.
- **`BBLIP_instances.json`**: stores the generated instances as a Python dictionary.

---

## BLIPI Instance

The **BLIPI** folder contains the generated **BBLIP** test instances and the code for generating them.

- **`BLIPI_instances.py`**: generates random test instances and writes them to `BLIPI_instances.json`.
